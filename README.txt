GAMEVAULT - START HERE

1. Extract this ZIP to a short path such as C:\GameVault_Connected
2. Open Command Prompt in that folder.
3. Run: npm install
4. Run: npx expo start --clear
5. Open Expo Go on your phone and scan the QR code.
6. Keep the phone and PC on the same Wi-Fi.

If LAN does not work, run: npx expo start --tunnel

Do not copy node_modules or .expo when sharing the project.
Store connection buttons are prototype UI only.
